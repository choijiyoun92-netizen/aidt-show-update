# AI 디지털 교육자료 웹전시관 목업 v10

첨부 캡처의 실제 웹전시관 분위기에 맞춰 정리한 VS Code 확인용 정적 목업입니다.

## 실행 방법

1. ZIP 압축을 해제합니다.
2. VS Code에서 `aidtshow-mockup-v10` 폴더를 엽니다.
3. `index.html`을 브라우저로 직접 열거나 VS Code 확장 프로그램 `Live Server`로 실행합니다.

## 구성 파일

- `index.html` : 화면 구조
- `style.css` : 실제 웹전시관 캡처 기반 UI 스타일
- `script.js` : 상단 GNB 화면 전환, 학교급/과목/학년/학기/발행사 필터, FAQ/소식 탭 동작

## 반영 방향

- 상단 안내 문구를 실제 웹전시관처럼 배치
- 웹전시관 첫 화면은 로고/학교급 탭/과목·학년 필터/좌측 상세 필터/교육자료 카드 구조로 재정리
- 웹 전시관 외 메뉴는 동일한 톤의 카드형 하위 페이지로 구성
- 검색 설정은 브라우저 `localStorage`에 저장되도록 구현

## 실제 연동 시 교체 필요 영역

- `script.js`의 `PRODUCTS` 데이터
- `script.js`의 `NEWS_ITEMS` 데이터
- 카드의 `href="#"` 링크
- 자료실 다운로드/문의 접수 버튼의 실제 링크 또는 API
